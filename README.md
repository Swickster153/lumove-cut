# Lumove Cut

A desktop video editor for Windows with built-in game, screen, webcam, and audio capture.

- **Website:** https://swickster153.github.io/lumove-cut/
- **Download:** [latest release](https://github.com/Swickster153/lumove-cut/releases/latest)
- **Report a bug:** [open an issue](https://github.com/Swickster153/lumove-cut/issues/new/choose) — in the app, use *Help → Report a Bug…* and attach your log from *Help → Open Logs Folder*.

This repository hosts releases, the website, and bug reports. The application source is not public.
