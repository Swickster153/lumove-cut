Questions

Is it really free?

Yes. Every feature works in the free version. The only difference is export resolution: free exports go up to 720p, and a Supporter license unlocks 1080p and above.

Windows says "Windows protected your PC" when I run the installer.

The alpha isn't code-signed yet, so Windows SmartScreen doesn't recognize it. Click More info → Run anyway. Only do this for installers downloaded from this site's Download button.

How do I activate my Supporter license?

After purchase you'll get a license key by email. In Lumove Cut, open Help → Supporter License…, paste the key, and click Activate. You need to be online once to activate; after that it works offline.

Can I use my license on more than one computer?

Yes — up to 3. To move it, deactivate it on the old computer from the same dialog.

What does "alpha" mean here?

It's an early version: usable for real projects, but expect bugs. Keep backups of important projects and recordings, and report anything that breaks.

I found a bug. Where do I report it?

In the app, use Help → Report a Bug… and attach your log from Help → Open Logs Folder. Or open an issue on GitHub.

What do I need to run it?

Windows 10 or 11, 64-bit. For smooth game capture, a GPU with hardware video encoding (NVIDIA, Intel, or AMD) is recommended; Lumove Cut falls back to software encoding otherwise.
